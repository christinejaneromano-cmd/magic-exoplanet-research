# magic-exoplanet-research
Light curve data and analysis for an exoplanet research project conducted through the MAGIC Summer Research Program.

**Project Overview**

This repository contains the raw light curve data and analysis files used for an exoplanet research project conducted through the MAGIC Summer Research Program.

This project uses data from the Kepler Space Telescope's K2 Mission, Campaign 10 to identify and estimate the basic parameters of two exoplanets from stellar light curves.

**Contents**

"Epic 201437844 Corrected Light Curve Data.txt"

Contains the original data used in the analysis.
  - .txt files are downloaded directly from MAST, an archive of the Kepler missions.
  - The data includes measurements of stellar brightness over time.

"EPIC 201437844 Exoplanet Analysis.ods"

Contains the spreadsheet used to analyze the visual light curve data.
  - Contains the imported light curve data, graphs, transit measurements, and calculations used to estimate the planets' parameters.

"Characterizing Exoplanets Using Kepler Space Telescope Data.docx"

Contains the project report/research paper for this project, with the full project process, results, insights, and verifications.

**Analysis Methods**

The light curve data was imported into Google Sheets and plotted as a scatter plot of stellar flux (brightness) versus time. Periodic decreases in stellar brightness were identified as planetary transits.

Transit depths were used to estimate the relative sizes of planets compared to their host star. Published stellar parameters were then used to estimate the planets' sizes in terms of Earth radii.

The time between successive transits was used to determine the orbital period of the planets. Published stellar parameters were also used to estimate the average distance between each planet and the star in AU.

**Data Source**

The light curve data was obtained from the Kepler/K2 space telescope data archive.
